    `Signature 434.5..524.3 / BodySlot3 524.3..651.1 / BodySlot2 651.1..777.9 /
     BodySlot1 777.9..904.3 / Salutation 904.3..1004.3`。
  - 换算成纸面比例后，槽位中心 `[0.1207, 0.2668, 0.4380, 0.6088, 0.7616]`，

    `[0.1712, 0.3186, 0.4667, 0.6133, 0.7623]` → **前 3 个槽分别偏 0.050 / 0.052 / 0.029**（≈ 37 / 39 / 21 px）。
